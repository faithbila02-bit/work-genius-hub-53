# Work Genius Hub

Build a modern, responsive web application called AI Workplace Productivity Assistant that helps users save time and improve productivity using artificial intelligence.

The application should include five main features:

Smart Email Generator: Generate professional emails in different tones, such as formal, friendly, and persuasive.

Meeting Notes Summarizer: Summarize long meeting notes and extract key points, decisions, action items, and deadlines.

AI Task Planner: Create, organize, prioritize, and track tasks, deadlines, and daily schedules.

AI Research Assistant: Research topics, summarize information, and provide reliable references when available.

AI Chatbot: Answer questions and assist users with everyday workplace tasks through an interactive chat interface.

Design Requirements:

Create a modern dashboard with sidebar navigation.

Use a clean blue-and-white colour scheme.

Include attractive cards, simple icons, productivity statistics, recent activities, and saved results.

Make the application fully responsive on desktop, tablet, and mobile devices.

Include editable AI outputs, copy buttons, loading indicators, and clear error messages.

Technical Requirements:

Use React, TypeScript, and Tailwind CSS.

Integrate a real AI service securely.

Use reusable components and responsive layouts.

Allow users to create, edit, complete, and delete tasks.

Allow users to save, search, copy, and delete generated results.

Ensure all buttons, forms, and navigation links work correctly.

Include realistic sample data if needed for demonstration.

If AI credentials are unavailable, provide clearly labelled demo functionality.
